# AGENTS.md

## What this repository is

A kit of agent skills built around `ticket-index`: a generated, three-level index over
Markdown tickets. The core skill and its Python script live in
`skills/ticket-index/`. Companion skills cover the ticket lifecycle and the disciplines
around it. `README.md` explains the workflow; `docs/` holds the concepts and reference.

## Commands

```bash
python scripts/verify.py                  # unit tests + demo cycle + installer
python -m unittest discover -s tests -v   # unit tests only
```

Run `verify.py` before claiming a change is complete. It is the same command CI runs.

## Rules

- Ticket frontmatter is the source of truth. Never store a derived fact (status, owner,
  counts, hierarchy) in the generated index or in `ticket-index.toml`.
- `docs/tickets/`, `examples/demo/docs/tickets/`, and any file containing
  `<!-- generated by ticket-index; do not edit -->` are generated. Change the tickets or
  the configuration, then run `render`.
- Keep `render` deterministic: no timestamps, absolute paths, network access, or
  unordered iteration in the output path.
- A new behaviour needs a test in `tests/` before or with the code.
- If you copy material from another project, record its author, license, and URL in
  `THIRD-PARTY-NOTICES.md`.

## Conventions

- Skills: `skills/<name>/SKILL.md`, with `name` and `description` frontmatter. Add
  `agents/openai.yaml` for user-invoked skills. Keep reference material in sibling files.
- Python: 3.11+, standard library only. The index script must not grow dependencies.
- Markdown: English scaffolding; ticket summaries and bodies may use any language.
